# Toth

Toth é uma aplicação de linha de comando gratuita, de código aberto e cross-platform escrito em Rust para criar livros utilizando Markdown.

## Funcionalidades

- **Gratuito e de código aberto**

- **Cross-platform**
  - Roda no Linux, macOS e Windows
  - Construído utilizando Rust

- **Customização do livro**
  - Configure os metadados do livro
  - Customize as estruturas e apresentação do livro

- **CLI workflow**
  - Gere livros diretamente do terminal
  - Desenvolvido para automação e integração em workflows existentes
