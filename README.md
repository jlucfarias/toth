# Toth

Toth is a free, open-source, cross-platform CLI application written in Rust for creating books from Markdown.

## Features

- **Free and open source**

- **Cross-platform**
  - Runs on Linux, macOS, and Windows
  - Built with Rust

- **Book customization**
  - Configure book metadata
  - Customize the book's structure and presentation

- **CLI workflow**
  - Generate books directly from the command line
  - Designed for automation and integration into existing workflows
